개인정보 처리방침

다비드 가계부 · 최종 수정일 2026년 8월 1일

앱은 어떤 개인정보도 수집하거나 외부로 전송하지 않습니다. 입력한 모든 내용은 사용하는 기기 안에만 저장됩니다.

수집하는 정보

없습니다.

앱에는 회원가입이나 로그인 기능이 없고, 계정이라는 개념 자체가 없습니다. 이름, 이메일, 전화번호, 위치, 연락처, 기기 식별자를 요구하지 않으며 수집하지도 않습니다.

입력한 내용의 저장 위치

가계부에 기록한 내역(금액, 사용처, 카테고리, 날짜, 메모)과 예산, 설정값은 기기 내부 저장 공간에만 보관됩니다.

  • 앱을 삭제하면 함께 삭제되며, 개발자는 복구할 수 없습니다.
  • 개발자를 포함한 누구도 이 데이터를 열람할 수 없습니다.
  • 서버로 전송되지 않습니다. 앱에는 네트워크 통신 코드가 없습니다.

외부 전송 및 제3자 제공

앱은 인터넷에 연결하지 않습니다. 분석 도구(Analytics), 광고 SDK, 충돌 리포트 수집 도구를 사용하지 않으며, 제3자에게 제공하거나 판매하는 정보가 없습니다.

기기 기능 사용

앱이 사용하는 기기 기능과 그 목적입니다.

기능목적비고
알림 매일 저녁 기록 알림, 예산 초과 알림 기기 안에서 예약되는 로컬 알림입니다. 외부 서버에서 보내는 푸시 알림을 사용하지 않습니다.
Face ID / Touch ID / 기기 암호 앱 잠금 해제 iOS가 인증 성공 여부만 앱에 알려줍니다. 생체 정보 자체는 앱이 접근할 수 없으며 저장하지도 않습니다.
공유 시트 카드 승인 문자로 내역 추가 사용자가 직접 공유한 문자만 처리하며, 처리는 전부 기기 안에서 이루어집니다. 앱은 문자 메시지를 스스로 읽을 수 없습니다.

각 기능은 사용자가 설정에서 켜거나 끌 수 있고, 거부해도 나머지 기능은 정상 동작합니다.

데이터 내보내기

설정 화면에서 기록한 내역을 CSV 파일로 내보낼 수 있습니다. 이 동작은 사용자가 직접 실행할 때만 일어나며, 파일을 어디에 저장하고 누구에게 보낼지는 전적으로 사용자가 선택합니다. 개발자는 이 파일에 접근하지 않습니다.

아동의 개인정보

방침 변경
